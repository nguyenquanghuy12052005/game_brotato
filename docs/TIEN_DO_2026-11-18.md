## Sự cố cuối phiên

Unity tự tắt với lỗi `Failed to present D3D11 swapchain due to device reset` — Windows reset driver GPU (TDR), không phải lỗi code hay lỗi dự án. Log cho thấy game vẫn chạy đúng tới `GAME OVER` rồi mới sập.

**Không mất file nào.** Đã kiểm tra: mọi thay đổi đều ghi xuống đĩa trước khi sập.

- File `Assets/_Recovery/0.unity` Unity tạo lại khi mở lần sau **giống hệt** `Assets/Scenes/GameScene.unity` (cùng MD5 `4CBF8D90…`) → không có gì cần phục hồi, **xoá được thư mục `_Recovery`**.
- Nếu hay bị lặp: cập nhật driver GPU, hoặc đổi Graphics API sang D3D12 (Project Settings > Player > Other Settings).
